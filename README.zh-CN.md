## 项目简介
**蜂群AI(Apiswarm AI，名称由 Apis+Swarm 组成：Apis为拉丁语“蜜蜂”，Swarm意为蜂群)**
蜂群AI是一款基于 Python 开发的轻量多实例任务调度平台，本地不运行大模型，仅负责任务排队调度、向云端大模型转发指令、接收并整理返回数据，设备负载极低。复杂任务由用户预先拆解并编写任务清单，系统调度数十个「小蜜蜂」实例并行处理。

项目全平台兼容，Windows、Linux、macOS 均可直接部署；也可通过刷机安装在电视盒子等低功耗硬件上，实现7×24小时无人值守挂机运行。支持本地目录、远程邮箱两种任务提交方式，结果按需取回，适用软件开发、文稿剧本撰写、漫画制作等大批量AI作业场景。

## 核心特性
- 全平台适配：纯 Python 实现，兼容 Windows/Linux/macOS；电视盒子刷入 Linux 后也可部署
- 资源占用极低：核心运算交由云端大模型完成，本地仅处理调度/转发/数据整理
- 全天候挂机：全设备支持 24 小时值守，低功耗设备（电视盒子等）性价比突出
- 多实例并行加速：数十个实例并发执行，批量任务效率显著提升
- 人工自主编排任务：自定义任务拆分、执行顺序与依赖关系，流程完全可控
- 文件级任务依赖：前置文件未生成时自动延后任务，保障逻辑有序
- 规范目录输出：结果按预设结构自动归档，便于查阅与二次使用
- 双模式任务下发：支持本地目录提交、远程邮件下发两种方式
- 邮件远程交互：邮件完成任务下发/状态查询/结果调取，隐私性与自主性更强
- 依赖校验机制：自动校验前置任务状态，规避并行执行引发的接口/格式问题

## 适用场景
### 软件开发
拆分项目模块/功能单元并编写任务清单 → 多实例并行调用云端模型生成代码 → 按依赖规则执行，结果归档，适配工程项目、Linux 内核模块等批量开发场景。

### 内容创作
拆分小说章节、剧本台词、漫剧分镜等子任务 → 集群并行创作 → 内容自动归类，高效完成系列化内容产出。

### 通用自动化作业
批量文案撰写、文档整编、素材处理等标准化工作，编写清单后自动化执行，输出文件统一规整。

## 快速开始
### 环境要求
| 类型 | 要求 |
|------|------|
| 系统 | Windows/Linux/macOS；电视盒子（刷Linux）、安卓设备（Termux）、迷你工控机等 |
| Python | 3.10 及以上版本 |
| 网络 | 可访问外网、邮件服务、云端大模型接口 |
| 其他 | 开启 POP3/SMTP 的邮箱账号；云端大模型 API 密钥（如 DeepSeek） |

### 安装步骤
1. 下载源码
```bash
# 克隆仓库（推荐）
git clone https://github.com/CCking2022/apiswarm-ai.git
# 或下载源码包解压
```

2. 安装依赖

```bash
cd apiswarm-ai
pip install -r requirements.txt
```

3. 配置项目

- 复制`config.yaml.example`并重命名为`config.yaml`，配置云端大模型、接口地址、邮件参数、任务 / 输出目录等

- 复制`.env.example`并重命名为`.env`，填写大模型 API Key与邮箱授权码后启动项目。

4. 启动服务

```bash
python main.py
```

### 提交任务

#### 方式 1：本地下发

将编写好的任务清单文件拷贝至配置文件指定的任务目录，系统自动识别调度。

#### 方式 2：远程邮件下发

- 下发任务：发送标题为 `newtask` 的邮件，附件为 1~n 个任务文件

- 查询状态：发送标题为 `status` 的邮件

- 调取结果：发送标题为 `download:目录名` 的邮件（如 `download:story`），系统会打包指定输出目录文件回传

### 获取结果

- 本地：直接进入预设输出目录查看

- 远程：发送结果调取指令邮件，等待系统回传压缩包

## 工作流程

### 本地下发任务

1. 任务预处理：拆解需求、配置依赖 / 输出规则、编写任务清单

2. 服务常驻：启动系统，后台监听任务目录 / 邮件指令

3. 提交任务：拷贝任务清单至指定目录

4. 依赖检测：校验依赖文件，未就绪则延后任务

5. 指令转发：向云端大模型发送请求，接收返回数据

6. 数据归档：按预设目录整理保存文件

7. 获取结果：本地查看或邮件远程调取

### 远程邮件下发任务

1. 任务预处理：拆解需求、编写任务清单

2. 服务常驻：后台监听邮件指令

3. 远程下发：发送指定格式邮件（标题 `newtask` + 任务清单附件）

4. 依赖检测 / 调度 / 归档：同本地模式

5. 获取结果：发送邮件指令调取结果

## 常见问题 (FAQ)

### Q1：电视盒子如何刷机部署？

A1：需先将电视盒子刷入 Linux 发行版（如 Armbian），再按常规步骤安装 Python 环境与项目依赖。

### Q2：支持哪些云端大模型？

A2：理论上兼容所有提供 API 接口的大模型（如 DeepSeek），需在 `config` 文件中配置对应接口地址与参数。

### Q3：邮件指令收不到响应怎么办？

A3：检查：① 邮箱 POP3/SMTP 服务是否开启；② 网络是否能访问邮件服务器；③ `config` 中邮件参数配置是否正确。
